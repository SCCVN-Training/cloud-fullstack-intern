# 1. Introduction

User personas are fictional representations of the primary users of SkillVerse. They help the development team understand user goals, motivations, behaviors, and challenges so that the platform can be designed to meet real user needs.

The personas in this document represent the target audience for the Minimum Viable Product (MVP).

---

# 2. Persona Overview

| Persona | Role                        | Primary Goal                                     |
| ------- | --------------------------- | ------------------------------------------------ |
| Emma    | University Student          | Learn affordable practical skills                |
| David   | Working Professional        | Share expertise and earn Skill Coins             |
| Sophia  | Hobbyist & Lifelong Learner | Explore new interests through community learning |
| Alex    | Platform Administrator      | Maintain a safe and reliable platform            |

---

# 3. Persona 1 – Emma (University Student)

### Profile

* **Age:** 21
* **Occupation:** Computer Science Student
* **Experience:** Beginner
* **Technical Skill:** Intermediate

### Background

Emma wants to improve her practical skills before graduation. She has limited financial resources and prefers learning from experienced people through interactive sessions rather than purchasing expensive online courses.

### Goals

* Learn practical skills.
* Find trustworthy teachers.
* Book learning sessions easily.
* Build experience for future employment.

### Frustrations

* High course fees.
* Difficulty identifying qualified instructors.
* Too many scattered learning resources.
* Limited opportunities for personalized learning.

### Needs

* Affordable learning opportunities.
* Easy skill search.
* Transparent teacher profiles.
* Simple booking process.

### Typical User Journey

```text
Register
    ↓
Complete Profile
    ↓
Search Skills
    ↓
View Teacher Profile
    ↓
Book Session
    ↓
Learn
    ↓
Leave Review
```

# 4. Persona 2 – David (Working Professional)

### Profile

* **Age:** 30
* **Occupation:** Software Engineer
* **Experience:** Advanced
* **Technical Skill:** Expert

### Background

David enjoys mentoring others and believes knowledge should be shared within the community. He wants an easy way to teach programming and technology skills outside his regular job while earning Skill Coins to learn photography and cooking.

### Goals

* Share professional expertise.
* Build a positive reputation.
* Earn Skill Coins.
* Learn unrelated skills from others.

### Frustrations

* Existing platforms focus on paid tutoring.
* Difficult to organize community teaching.
* Limited recognition for volunteer teaching.

### Needs

* Easy skill publishing.
* Booking management.
* Reputation through ratings and reviews.
* Fair virtual reward system.

### Typical User Journey

```text
Register
    ↓
Create Teaching Profile
    ↓
Publish Skill
    ↓
Receive Booking Request
    ↓
Accept Session
    ↓
Teach
    ↓
Receive Skill Coins
```

# 5. Persona 3 – Sophia (Hobbyist & Lifelong Learner)

### Profile

* **Age:** 27
* **Occupation:** Graphic Designer
* **Experience:** Intermediate
* **Technical Skill:** Intermediate

### Background

Sophia enjoys learning creative hobbies such as painting, photography, and cooking. She also enjoys teaching digital illustration and believes learning should be collaborative and enjoyable.

### Goals

* Discover new hobbies.
* Teach creative skills.
* Participate in community activities.
* Build long-term learning relationships.

### Frustrations

* Community events are difficult to discover.
* Learning communities often disappear quickly.
* Few platforms encourage reciprocal teaching.

### Needs

* Friendly user interface.
* Active community.
* Flexible skill exchange.
* Reliable recommendations based on interests.

### Typical User Journey

```text
Browse Skills
      ↓
Book Session
      ↓
Learn
      ↓
Teach Another Skill
      ↓
Continue Exchanging Knowledge
```

# 7. Shared User Needs

Across all personas, users expect SkillVerse to provide:

* Secure user authentication.
* Easy navigation.
* Responsive design.
* Reliable booking management.
* Trustworthy user profiles.
* Fair Skill Coin transactions.
* Stable platform performance.

---

# 8. Design Implications

The identified personas influence the design of SkillVerse in several ways:

| User Need               | Design Decision                                   |
| ----------------------- | ------------------------------------------------- |
| Easy navigation         | Simple and intuitive interface                    |
| Trustworthy teachers    | Ratings, reviews, and detailed profiles           |
| Affordable learning     | Skill Coin exchange system                        |
| Efficient booking       | Streamlined booking workflow                      |
| Community participation | User-generated skill listings and reviews         |
| Reliability             | Secure authentication and stable backend services |

---

# 9. Summary

The four personas represent the primary users of SkillVerse and provide a user-centered foundation for the project's requirements and design.

Understanding these users ensures that future decisions regarding features, database design, APIs, and user interface development remain aligned with real-world needs throughout the Software Development Life Cycle.
