# Project Roadmap

**Project Name:** SkillVerse – Community Skill Exchange

**Document Version:** 1.0

**Author:** Nhu Le Nguyen Quynh

**Last Updated:** July 16, 2026

---

# 1. Introduction

This Project Roadmap outlines the planned implementation timeline for the SkillVerse project during the 10-week SCC Cloud Fullstack Internship.

The roadmap aligns project activities with the Software Development Life Cycle (SDLC) and the internship curriculum. It provides a high-level view of milestones, deliverables, and expected outcomes for each phase of development.

---

# 2. Project Objectives

The objectives of this roadmap are to:

* Deliver a functional Minimum Viable Product (MVP) within 10 weeks.
* Apply SDLC principles throughout the project lifecycle.
* Follow Agile and incremental development practices.
* Gain hands-on experience with modern cloud-native technologies.
* Deploy the application to AWS using CI/CD pipelines.

---

# 3. Development Strategy

The project will follow an incremental and iterative development approach.

Each week will conclude with measurable deliverables that build upon the previous week's work. Core features will be implemented first, followed by cloud deployment, infrastructure automation, and monitoring.

---

# 4. Project Timeline

| Week   | Focus Area                      | Major Deliverables                                                                  |
| ------ | ------------------------------- | ----------------------------------------------------------------------------------- |
| **1**  | Planning & Project Setup        | Repository setup, Git workflow, README, SDLC documentation, GitHub Actions skeleton |

| **5**  | Integration & Testing           | Frontend-backend integration, unit testing, API testing, debugging                  |
| **6**  | AWS Cloud Services              | Deploy backend, configure AWS services, storage, secrets management                 |
| **7**  | CI/CD & Cloud Deployment        | GitHub Actions pipeline, Docker containerization, cloud deployment                  |
| **8**  | Microservices Preparation       | Service separation, API improvements, scalability planning                          |
| **9**  | Infrastructure as Code          | Terraform, Kubernetes basics, infrastructure provisioning                           |
| **10** | Monitoring & Final Presentation | Monitoring, logging, optimization, documentation updates, final demo                |

# 8. Success Criteria

The project will be considered successful if it meets the following objectives:

* MVP features are fully implemented.
* Frontend and backend are successfully integrated.
* RESTful APIs operate correctly.
* PostgreSQL database is stable and reliable.
* Unit and integration tests pass.
* Application is deployed to AWS.
* CI/CD pipeline is functional.
* Infrastructure is provisioned using Terraform.
* Project documentation is complete and up to date.
* Final project demonstration is successfully delivered.

---

# 9. Assumptions

The roadmap assumes that:

* The internship follows the planned 10-week schedule.
* Required technologies (Angular, FastAPI, PostgreSQL, AWS, Docker, Terraform, Kubernetes) are available.
* Development progresses without major schedule disruptions.
* AWS resources and development tools remain accessible throughout the project.

---

# 10. Constraints

The project is subject to the following constraints:

* Limited to a 10-week internship duration.
* Developed primarily by a single intern.
* Scope focuses on delivering an MVP rather than a production-ready platform.
* Advanced features may be deferred to future releases if necessary.

---

# 11. Future Enhancements

Features planned beyond the MVP include:

* Real-time chat
* Push notifications
* AI-powered skill recommendations
* Video meeting integration
* Social login
* Gamification and achievement badges
* Mobile application support

---

# 12. Roadmap Summary

The SkillVerse roadmap provides a structured execution plan that aligns the project with the internship curriculum and the Software Development Life Cycle (SDLC). By delivering incremental milestones each week, the project aims to achieve a fully functional cloud-based MVP within the internship timeframe while establishing a solid foundation for future enhancements.
