# Stakeholder Analysis

**Project Name:** SkillVerse – Community Skill Exchange

**Document Version:** 1.0

**Author:** Nhu Le Nguyen Quynh

**Last Updated:** July 16, 2026

---

# 1. Introduction

Stakeholders are individuals, groups, or organizations that influence, use, support, or are affected by the development and operation of SkillVerse.

Understanding stakeholder expectations helps ensure that the system satisfies both business objectives and user needs throughout the Software Development Life Cycle (SDLC).

---

# 2. Stakeholder Identification

The primary stakeholders for SkillVerse are:

* Learners
* Teachers
* Platform Administrator
* Developer
* Internship Mentor

---

# 3. Stakeholder Overview

| Stakeholder            | Role                 | Interest                                                    |
| ---------------------- | -------------------- | ----------------------------------------------------------- |
| Learners               | End User             | Learn new skills through the platform                       |
| Teachers               | End User             | Share knowledge and earn Skill Coins                        |
| Platform Administrator | System Administrator | Manage users, content, and platform operations              |
| Developer              | Software Engineer    | Design, develop, test, deploy, and maintain the application |
| Internship Mentor      | Project Reviewer     | Evaluate technical implementation and internship outcomes   |

---

# 4. Stakeholder Responsibilities

## 4.1 Learners

### Responsibilities

* Register an account.
* Search available skills.
* Request learning sessions.
* Participate in booked sessions.
* Leave ratings and reviews.

### Expectations

* Easy navigation.
* Reliable booking process.
* Affordable learning opportunities.
* Trustworthy instructors.
* Responsive user interface.

---

## 4.2 Teachers

### Responsibilities

* Create teaching profiles.
* Publish skill listings.
* Accept or decline learning requests.
* Conduct learning sessions.
* Receive Skill Coins.

### Expectations

* Easy skill management.
* Fair reward system.
* Positive reputation through reviews.
* Simple booking management.

---

## 4.3 Platform Administrator

### Responsibilities

* Manage user accounts.
* Monitor reported content.
* Maintain system integrity.
* Support platform operations.

### Expectations

* Administrative dashboard.
* User management tools.
* Reliable system performance.
* Secure data management.

---

## 4.4 Developer

### Responsibilities

* Plan the project.
* Design the system architecture.
* Develop frontend and backend components.
* Configure cloud infrastructure.
* Implement testing and deployment.
* Produce technical documentation.

### Expectations

* Clean project structure.
* Maintainable codebase.
* Stable development workflow.
* Successful project delivery within 10 weeks.

---

## 4.5 Internship Mentor

### Responsibilities

* Review project progress.
* Provide technical guidance.
* Evaluate deliverables.
* Assess software engineering practices.

### Expectations

* Professional documentation.
* Consistent Git workflow.
* SDLC compliance.
* Functional cloud deployment.
* Demonstration of acquired technical skills.

# 8. Success Factors

The project should satisfy stakeholder expectations by:

* Providing an intuitive and responsive user experience.
* Supporting efficient skill exchange and booking management.
* Maintaining secure and reliable system operation.
* Delivering complete technical documentation.
* Following Agile SDLC practices throughout development.
* Completing the MVP within the internship timeline.

---

# 9. Summary

Stakeholder analysis establishes a clear understanding of everyone who influences or benefits from SkillVerse.

By identifying stakeholder roles, responsibilities, expectations, and communication methods early in the planning phase, the project team can make informed decisions throughout development while ensuring that the final product aligns with both user needs and internship objectives.
